# SKILL 6 — Redundancy & Friction Eliminator

Evaluation of Redundancy and Friction in Apps and SaaS

---

# SKILL OBJECTIVE

Evaluate whether the application contains **unnecessary steps, redundant features, or interactions that increase user effort**.

This skill identifies:

* interface redundancies
* unnecessary steps
* duplicated functionality
* excessive clicks
* avoidable friction in the experience

It answers the question:

> **Is there anything in the product that could be removed without reducing its value?**

---

# USAGE CONTEXT

Use this skill when:

* the app already has **complete user flows**
* multiple screens and features are implemented
* you want to optimize **experience efficiency**

This analysis is common in:

* UX audits
* SaaS optimization
* product simplification
* pre-launch refinement

---

# REQUIRED INPUT

Before starting the evaluation, provide:

**1 — App name**

**2 — Main product flows**

**3 — List of existing features**

**4 — Main screens of the application**

**5 — Most frequent user tasks**

---

# STEP 1 — FEATURE REDUNDANCY

Evaluate whether there are **features that perform essentially the same function**.

Questions:

* Are there duplicated features?
* Could some functions be merged?
* Are there modules that are rarely used?

Scoring:

| Redundancy | Score |
| ---------- | ----- |
| Very high  | 1     |
| High       | 2     |
| Moderate   | 3     |
| Low        | 4     |
| Very low   | 5     |

---

# STEP 2 — UNNECESSARY STEPS

Evaluate whether flows include **steps that could be removed**.

Questions:

* Are there unnecessary clicks?
* Does the user have to confirm simple actions?
* Are there unnecessary intermediate screens?

Scoring:

| Step efficiency  | Score |
| ---------------- | ----- |
| Very inefficient | 1     |
| Inefficient      | 2     |
| Moderate         | 3     |
| Efficient        | 4     |
| Highly efficient | 5     |

---

# STEP 3 — UNNECESSARY COMPLEXITY

Evaluate whether the product demands **more effort than necessary**.

Questions:

* Are there too many required fields?
* Does the user need to input repeated information?
* Are there unnecessary complex decisions?

Scoring:

| Complexity | Score |
| ---------- | ----- |
| Very high  | 1     |
| High       | 2     |
| Moderate   | 3     |
| Low        | 4     |
| Very low   | 5     |

---

# STEP 4 — OPERATIONAL LOAD

Evaluate the effort required to complete common tasks.

Questions:

* Do frequent tasks require many steps?
* Are there automation opportunities?
* Does the user repeat actions manually?

Scoring:

| Operational load | Score |
| ---------------- | ----- |
| Very high        | 1     |
| High             | 2     |
| Moderate         | 3     |
| Low              | 4     |
| Very low         | 5     |

---

# STEP 5 — SYSTEM EFFICIENCY

Evaluate whether the system helps users complete tasks faster.

Questions:

* Are there shortcuts?
* Are there reusable patterns?
* Does the system learn from user behavior?

Scoring:

| System efficiency | Score |
| ----------------- | ----- |
| Very low          | 1     |
| Low               | 2     |
| Moderate          | 3     |
| Good              | 4     |
| Excellent         | 5     |

---

# STEP 6 — FEATURE CLARITY

Evaluate whether every feature has a **clear purpose**.

Questions:

* Do users understand the purpose of each feature?
* Are there elements that feel unnecessary?
* Are there rarely used features?

Scoring:

| Feature clarity | Score |
| --------------- | ----- |
| Very low        | 1     |
| Low             | 2     |
| Moderate        | 3     |
| Good            | 4     |
| Excellent       | 5     |

---

# FINAL SCORE CALCULATION

Add all scores.

Maximum score: **30**

---

# INTERPRETATION

| Score | Diagnosis                        |
| ----- | -------------------------------- |
| 0–10  | Product with high redundancy     |
| 11–18 | Product with moderate redundancy |
| 19–24 | Efficient product                |
| 25–30 | Highly optimized product         |

---

# FINAL DIAGNOSIS

After scoring, generate:

**1 — Identified redundancies**

**2 — Steps that can be removed**

**3 — Features that can be merged**

**4 — Processes that can be automated**

**5 — Recommended simplifications**

---

# FINAL RESULT

Classification:

❌ Redundant product
⚠️ Reasonably optimized product
✅ Efficient product
🚀 Extremely lean product

---

# CORE PRINCIPLE

> Good products add value.
> Great products remove friction.

Eliminating redundancy:

* reduces effort
* speeds up tasks
* improves experience
* increases retention

This skill ensures the product remains **simple, focused, and efficient**.
