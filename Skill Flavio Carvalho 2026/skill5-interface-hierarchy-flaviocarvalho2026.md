# SKILL 5 — Interface Hierarchy & Attention Map Evaluator

Evaluation of Visual Hierarchy and Attention Mapping in App and SaaS Interfaces

---

# SKILL OBJECTIVE

Evaluate whether the application's interface has a **clear visual hierarchy** and whether screen elements properly guide **user attention toward the most important areas**.

This skill analyzes:

* visual hierarchy
* attention distribution
* interface scanability
* element priority
* content organization

It answers the question:

> **Does the interface naturally guide the user’s eyes to what truly matters?**

---

# USAGE CONTEXT

Use this skill when:

* the app screens are already designed
* a functional layout or navigable prototype exists
* you want to validate whether the interface communicates priorities correctly

This skill helps prevent:

* confusing screens
* excessive elements competing for attention
* poor scanability
* loss of focus on key actions

---

# REQUIRED INPUT

Before starting the evaluation, provide:

**1 — App name**

**2 — Screen or section being analyzed**

**3 — Main objective of the screen**

**4 — Key interface elements (buttons, cards, tables, etc.)**

**5 — Screenshots or descriptions of the interface**

---

# STEP 1 — IDENTIFY THE PRIMARY ACTION

Evaluate whether the interface clearly communicates **the most important action on the screen**.

Questions:

* Is there a clear primary action?
* Can users quickly understand what to do?
* Does the primary button stand out?

Scoring:

| Primary action clarity | Score |
| ---------------------- | ----- |
| Very confusing         | 1     |
| Unclear                | 2     |
| Acceptable             | 3     |
| Clear                  | 4     |
| Very clear             | 5     |

---

# STEP 2 — VISUAL HIERARCHY

Evaluate whether screen elements have **appropriate visual priority**.

Questions:

* Are important elements larger or visually highlighted?
* Does the layout guide the user’s eye?
* Is there sufficient visual contrast?

Scoring:

| Visual hierarchy | Score |
| ---------------- | ----- |
| None             | 1     |
| Weak             | 2     |
| Moderate         | 3     |
| Good             | 4     |
| Excellent        | 5     |

---

# STEP 3 — SCANABILITY

Evaluate whether users can **quickly understand the screen content**.

Questions:

* Can the screen be understood in a few seconds?
* Are information blocks well organized?
* Are elements logically grouped?

Scoring:

| Scanability | Score |
| ----------- | ----- |
| Very low    | 1     |
| Low         | 2     |
| Moderate    | 3     |
| Good        | 4     |
| Excellent   | 5     |

---

# STEP 4 — ATTENTION DISTRIBUTION

Evaluate whether the interface avoids excessive competition between elements.

Questions:

* Are too many elements competing for attention?
* Does the user know where to look first?
* Is there visual balance?

Scoring:

| Attention distribution | Score |
| ---------------------- | ----- |
| Chaotic                | 1     |
| Disorganized           | 2     |
| Moderate               | 3     |
| Balanced               | 4     |
| Highly controlled      | 5     |

---

# STEP 5 — INTERFACE HOT ZONES

Identify **areas of highest visual attention on the screen**.

Questions:

* Are primary elements placed in high-attention zones?
* Does the layout follow reading patterns (F-pattern, Z-pattern)?
* Are critical elements positioned strategically?

Scoring:

| Strategic positioning | Score |
| --------------------- | ----- |
| Poor                  | 1     |
| Weak                  | 2     |
| Acceptable            | 3     |
| Good                  | 4     |
| Excellent             | 5     |

---

# STEP 6 — VISUAL NOISE

Evaluate whether unnecessary elements are present.

Questions:

* Are there redundant elements?
* Are decorative elements excessive?
* Is the interface clean?

Scoring:

| Visual noise | Score |
| ------------ | ----- |
| Very high    | 1     |
| High         | 2     |
| Moderate     | 3     |
| Low          | 4     |
| Very low     | 5     |

---

# FINAL SCORE CALCULATION

Add all scores.

Maximum score: **30**

---

# INTERPRETATION

| Score | Diagnosis             |
| ----- | --------------------- |
| 0–10  | Problematic hierarchy |
| 11–18 | Acceptable hierarchy  |
| 19–24 | Good visual hierarchy |
| 25–30 | Excellent hierarchy   |

---

# FINAL DIAGNOSIS

After scoring, generate:

**1 — Interface attention map**

**2 — Elements competing for attention**

**3 — Elements that should have more emphasis**

**4 — Strengths of the visual hierarchy**

**5 — Recommended adjustments**

---

# FINAL RESULT

Classification:

❌ Weak hierarchy
⚠️ Acceptable hierarchy
✅ Good hierarchy
🚀 Excellent hierarchy

---

# CORE PRINCIPLE

> Effective interfaces guide the user’s eyes without them noticing.

A strong visual hierarchy:

* prioritizes key actions
* reduces confusion
* increases task speed
* improves conversion

This skill ensures that **the interface communicates priorities clearly**.
