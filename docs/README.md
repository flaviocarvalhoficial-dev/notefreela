# Project Documentation & Resources

This directory contains resources for project planning, ideation, and prompts.

## Structure

- **`/prompts`**: Reusable AI prompt blocks, system instructions, and specific task prompts.
- **`/ideas`**: Brainstorming sessions, feature concepts, and future roadmap items.
- **`/notes`**: General project notes, meeting minutes, and quick thoughts.

Use this structure to keep the project root clean and organized.
